# 2026-11-08 問答紀錄

## Q：如果想要製作音樂的音軌（去背）的 mp4 檔，有模型或工具可以做到嗎？
A：有，分兩種需求。A) 音樂波形/頻譜動畫、背景透明，疊在 lofi 圖上：免費 FFmpeg（showwaves 波形、showfreqs/showspectrum 頻譜、avectorscope），可一行指令輸出；DaVinci Resolve（免費）、Blender（免費，聲音驅動動畫）；After Effects（付費，Audio Spectrum、Trapcode Sound Keys）；線上 Specterr、VEED（多半有浮水印或付費）。注意 mp4（H.264）不支援透明：要透明請輸出 .mov（ProRes 4444）或 .webm（VP9 alpha）；一定要 mp4 就用純綠/純黑底，剪輯軟體再去背或用「濾色/Screen」混合。B) 把音樂裡的人聲/伴奏分開（音訊去背）：Ultimate Vocal Remover（UVR5，免費、Windows 有安裝檔）、Demucs（Meta 開源）、線上 lalal.ai（付費）。本機目前沒有 ffmpeg，需要時告訴我，我列出下載來源與大小。

## Q：我要在 UI 工作流使用，有什麼做法？
A：在 ComfyUI 裡可用自訂節點：1) ComfyUI_RyanOnTheInside：幾乎所有節點都可被音訊/MIDI 驅動，含分離樂器與音訊反應視覺效果，適合做跟著音樂跳的波形/頻譜/特效；2) ComfyUI_Yvann-Nodes：分析音訊、分離人聲/鼓/貝斯，產生權重與遮罩驅動動畫，並可畫出音訊權重圖；3) 輸出影片搭配 ComfyUI-VideoHelperSuite（Video Combine 可合併音訊；透明背景需選 ProRes 4444 / webm 這類支援 alpha 的格式，mp4 不支援透明，可改黑底/綠底）。ComfyUI 新版也有內建 Load Audio / Save Video 等節點，但這次 ComfyUI 沒開，無法確認你的版本。建議流程：載入音樂 → 音訊特徵（或先分離人聲）→ 視覺化節點產生每格畫面（黑底或透明）→ Video Combine 合成音訊輸出。安裝都從 Manager 搜尋，裝好重開後通知我接工作流。

## Q：LoRA 換衣服、姿勢時畫風會變，想把畫風統一回來（附 Gemini 四方案），請依主機規格整理可行方案，可用雲端，先回覆再詢問是否執行
A：主機 RTX 2060 6GB／16GB RAM。方案1（LoRA 0.6～0.65＋畫風標籤）、方案2（雙 KSampler Advanced 前段有 LoRA、後段無 LoRA）免安裝，速度和現在一樣（約 30 秒）；方案3 IPAdapter 的模型與節點已安裝，可直接接，但之前實測 370～539 秒一張（RAM 不足，一直載入模型），可接受就用；方案4 Inspire Block Weight 需安裝，Gemini 給的向量 1,0,0,0,1,1,1,1,1,0.3,0.3,0.3 把 IN 層設 0，跟它說的「保留 IN/MID」矛盾，暫不建議。注意：ZUKI（zukiSoft）本身偏柔和，方案2 後半段交給底模可能更柔，要先判斷畫風來源；Gemini 建議 thick outlines／bold lineart，與現有提示詞 thin lineart、負向 thick lineart 衝突，需確認目標畫風。建議順序：步驟0 做 LoRA 0／0.6／1.0 比較圖 → 方案1＋2 → 不夠再方案3。雲端備案：RunPod／ComfyUI 雲端租 4090（付費，需同意）；根本解法是用多樣服裝與姿勢重新訓練 LoRA（Civitai 線上訓練或 Colab）。需要使用者提供目標畫風的原圖（圖2）。

## Q：我不是要雲端顯卡，我是要用雲端模型幫忙跑

## Q：不是用 Gemini，而是真的專業的雲端繪圖模型
A：你的 ComfyUI 已經內建官方 API 節點，不用安裝，在節點選單直接搜尋即可。依程式內的價格標籤：1) ByteDance Seedream 4.5/5.0：可放多張參考圖（角色＋畫風），動漫角色一致性強，約 US$0.035～0.09 一張；2) FLUX.2 Image / FLUX 3 Image（BFL）：多參考圖，約 US$0.03～0.075；3) OpenAI GPT Image 2.5：提示詞遵循度最好，價格依品質；4) Recraft V4 Create Style：用幾張原圖建立「專屬畫風」，之後每張都套同一個畫風，生圖約 US$0.0572；5) Krea 2 Style Reference、Qwen Image 3 Edit。流程：本機 ZUKI＋角色 LoRA＋骨架產生新衣服與姿勢（免費）→ 雲端節點接「角色圖＋原圖畫風參考」重繪 → 存檔。使用前要在 ComfyUI 右上角登入 Comfy 帳號並購買點數（使用者自己操作）。推薦先試 Seedream 5.0 與 FLUX.2 各一張比較。

## Q：只有一張原圖可以處理嗎？
A：可以。流程不變：① 本機 LoRA＋骨架出新衣服、新姿勢 → ② 雲端節點接兩張圖：圖1＝本機新圖（決定姿勢和衣服）、圖2＝那張唯一的原圖（決定畫風與長相）→ ③ 存檔。Seedream 5.0、Flux.2 一張參考圖就能正常用；提示詞寫明「圖1的姿勢、衣服、白底不變，只把線條、上色、配色、頭身比改成圖2」，避免把原圖的水手服抄回來。Recraft 建立專屬畫風一張也可以，但樣本少較不穩，建議放後面。要多張也能做：拿出比較滿意的成品再當參考圖，逐步累積。

## Q：原圖長這樣（水手服、黃底、只到大腿），沒有到腳，有機會嗎？
A：有機會。原圖在流程裡只負責「畫風」，全身與姿勢來自本機 LoRA＋骨架的圖1，腳的畫法模型會依同畫風補上；腿和鞋子的線條、上色方式比較靠模型推測，可能需要多抽幾次。這張原圖的畫風特徵：深藍色細線（不是黑色粗線）、平塗、硬邊兩階陰影且陰影偏藍、暖黃＋粉彩配色、大頭圓臉、腮紅斜線。提示詞要另外鎖住：白色背景（避免黃底被抄）、不要水手服或水手領、不要裙子。已把原圖複製到 ComfyUI\input\style_ref_original.webp。

## Q：這種雲端工作流運行時間大概多久？
A：估計值，實際以你第一次跑的為準。本機部分：ZUKI＋LoRA 28 步約 25～30 秒，加上 DWPose 抽骨架與 ControlNet，第一次要載入模型（RAM 16GB 會慢）約 1～2 分鐘，之後約 30～50 秒。雲端部分：Seedream 5.0 Lite（2K、有參考圖會自動開 thinking）約 20～60 秒；Flux.2 [pro] 約 10～30 秒；加上上傳、下載與排隊。雲端在對方伺服器上算，不吃你的顯卡和記憶體。合計：第一次約 2～4 分鐘，之後每次約 1～2 分鐘。省時間：本機角色滿意後，把本機 KSampler 的 seed 改 fixed，只改雲端提示詞再跑，本機部分會直接用快取，只跑雲端（約 30 秒～1 分鐘）；不需要比較時用 Ctrl+B 略過其中一個雲端節點。
