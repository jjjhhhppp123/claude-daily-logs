# 2026-11-07 問答紀錄

## Q：我可以在 UI 找到我的舊的 seed 嗎？
A：可以，三種方法：1) 最可靠：把 output 資料夾裡那張圖直接拖進 ComfyUI 畫布，會載入當時整個工作流（含 seed、提示詞），再把 KSampler 的「生成後控制」改成 fixed 就能重現；2) 左側「佇列／歷史」面板：每次執行都有紀錄，對項目按右鍵「載入工作流」；3) 左側媒體資產（輸出）面板點圖，同樣可載入工作流。注意：控制設 randomize 時，跑完後節點上顯示的是「下一次要用的」新 seed，不是剛剛那張的，要找舊 seed 請用圖檔或歷史紀錄。

## Q：（截圖：媒體資產右鍵選單）這邊嗎？
A：對，選「在新分頁中以工作流程開啟」，會開一個新分頁載入這張圖當時的整個工作流，取樣節點上的「種子」就是這張圖用的 seed；要重現就把「生成後控制」改 fixed 後執行。「匯出工作流程」可存成 json 備份。注意：只有經由 SaveImage 存的圖才有工作流資訊；input 資料夾裡的 gemini_edit_*.png 是 Gemini 節點另存的，沒有工作流可載入。
