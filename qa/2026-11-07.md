# 2026-11-07 問答紀錄

## Q：我可以在 UI 找到我的舊的 seed 嗎？
A：可以，三種方法：1) 最可靠：把 output 資料夾裡那張圖直接拖進 ComfyUI 畫布，會載入當時整個工作流（含 seed、提示詞），再把 KSampler 的「生成後控制」改成 fixed 就能重現；2) 左側「佇列／歷史」面板：每次執行都有紀錄，對項目按右鍵「載入工作流」；3) 左側媒體資產（輸出）面板點圖，同樣可載入工作流。注意：控制設 randomize 時，跑完後節點上顯示的是「下一次要用的」新 seed，不是剛剛那張的，要找舊 seed 請用圖檔或歷史紀錄。

## Q：（截圖：媒體資產右鍵選單）這邊嗎？
A：對，選「在新分頁中以工作流程開啟」，會開一個新分頁載入這張圖當時的整個工作流，取樣節點上的「種子」就是這張圖用的 seed；要重現就把「生成後控制」改 fixed 後執行。「匯出工作流程」可存成 json 備份。注意：只有經由 SaveImage 存的圖才有工作流資訊；input 資料夾裡的 gemini_edit_*.png 是 Gemini 節點另存的，沒有工作流可載入。

## Q：（九宮格）只加工作流製作圖 3 的骨架，再製作 LoRA 的角色姿勢，畫風完整不變，背景白色，衣服短袖短褲
A：把九宮格存成 input/pose_grid_9.png。以原始免費白底版為底新增：載入九宮格 → ImageCrop 裁出圖 3（寬高 410、x=839、y=4）→ DWPreprocessor 抽骨架（手/身體/臉、1024、yolox_l + dw-ll_ucoco_384_bs5，scale_stick_for_xinsr_cn 開，模型已下載過）→ 骨架預覽；ControlNet union promax → 模式 openpose → ControlNetApplyAdvanced（強度 0.85、0~0.8）→ 接回原本 KSampler。只用骨架、不讀參考圖顏色，所以畫風仍是 ZUKI＋mychar_01 LoRA。主模型、LoRA 1.0、1024、28 步、cfg 5、dpmpp_2m karras 不變。提示詞：服裝改 (white t-shirt:1.2), (short sleeves:1.3), light blue shorts；動作改 standing, (outstretched arms:1.3), (spread arms:1.2), happy, open mouth, smile, closed eyes；構圖 full body→cowboy shot（圖 3 只到大腿）。負向加 (long sleeves:1.3), hoodie, jacket，移除 cropped 相關。存「白底角色_3張開雙臂」。
