### Q：重繪的效果不是很好，有原因嗎？
**A：** 4 個原因：① 遮罩照舊短袖短褲輪廓只外擴 20px，寬褲沒空間；② ZUKI 不是重繪專用模型，遮罩填灰後邊緣易有殘影；③ 骨架腿是直的，傾向畫窄管；④ 自己加的「近白改背景色」處理把白褲陰影洗掉。局部重繪適合小範圍、形狀不變的修改（表情、顏色），不適合輪廓會變的大換裝。

### Q：（構想）骨架＋LoRA 做好動作圖，再用局部 LoRA 重繪保住手和臉？
**A：** 方向對，關鍵是反向遮罩：只保頭部與手掌，其他全部重畫；服裝 LoRA 非必要，要求每張衣服細節完全一樣時再加。

### Q：不是，重新一次畫好，但長袖露出手
**A：** 骨架（臉旁比YA）＋v2 LoRA 1.0 整張生成，提示詞 `long sleeves, fitted sleeves, sleeve cuffs, hands visible`，負面 `sleeves past wrists, sleeves past fingers, oversized sleeves`。結果：長袖袖口停在手腕、雙手完整露出、YA 手勢正確、姿勢跟骨架一致，臉與髮型一致；褲子焦糖色但仍偏直筒。

### Q：可以減少圖中黑色線條的部分嗎？
**A：** 拿掉 `clean lineart`，同 seed 測 2 種：
- ① 彩色細線：正面 `colored lineart, thin lineart, soft lineart, (brown lineart:1.1)`，負面 `black lineart, thick lineart, bold outline, black outline, dark outline`

### Q：去掉描邊線做得到嗎？

### Q：但我想先把背景風格調好，能不能完全不要有描邊？
**A：** 試後製：person_yolov8m-seg 抓人物遮罩（只留最大塊、切掉桌面）→ OpenCV black-hat 找比周圍暗的細線 → TELEA inpaint 用周圍顏色補 → 微柔化。背景描邊幾乎全去掉、人物不動，但補色只是「抹開」，花、馬克杯、筆記本、筆變模糊，像糊掉而非無線稿插畫，效果不理想。

### Q：尷尬，我如果加入別的 LoRA 就會打架
**A：** 角色 LoRA 的 42 張訓練圖都是同一畫風（平塗、黑細線、白背景），所以連畫風一起學進去，與 LofiGirl 都在改畫風而衝突。解法：A 畫風靠提示詞（現在可用、不衝突）；B 兩段取樣（前段 LofiGirl 強定構圖光影、後段角色 1.0 修臉，免安裝）；C LoRA 分層套用（需外掛）；D 根本解：下一版訓練混入 8～10 張不同畫風/有背景/無描邊圖，標籤寫畫風詞（flat color、lineart、white background），讓 LoRA 只記角色。

### Q：C 會很吃效能嗎？
**A：** 不會。分層只是載入時每層合併權重比例不同，生成速度、VRAM 與一般 LoRA 相同（約 40 秒），不像分區生成每步算兩套（6 分鐘）。成本是要裝 ComfyUI-Inspire-Pack（Lora Loader Block Weight）、十幾層比例要試、SDXL 臉與畫風常混在同層不保證切得乾淨。建議先試 B。

### Q：你剛剛提到的 C 模組叫什麼？它可以完全分離角色和背景嗎？可以看看目前主流的做法嗎？
**A：** C 是 ComfyUI-Inspire-Pack 的 `Lora Loader (Block Weight)`（block_vector 設每層強度，有預設組合）。它分的是「角色 vs 畫風」（模型的層），不是「人物區 vs 背景區」，所以不能完全分離角色與背景；只保留角色 LoRA 的長相層可減少黑線被帶進來，但人物線條也會變淡。社群經驗（非正式）：SDXL LoRA 角色長相多在 OUT0、畫風多在 OUT1（IN08 也有），建議用 XY 比較圖自己試。
主流做法：① 背景與角色分開畫再遮罩合成＋低強度重繪統一光線（最常見、6GB 可行）；② 分區提示詞／分區 LoRA（慢）；③ 分層套用；④ 重新訓練多畫風角色 LoRA（根本解）；⑤ 新一代圖片編輯模型（需大顯卡）。建議現在用 ①，下一版 LoRA 用 ④。
