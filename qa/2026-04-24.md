## Q: 把網站的結構移回 ChannelWebsite 資料夾

**操作步驟：**
1. 確認 ChannelWebsite 已有複製的 index.html 和 images/avatar.png
2. `git remote set-url origin https://github.com/xxx/xxx.github.io.git`（帳號已過濾）
3. `git add index.html images/`
4. `git commit -m "Consolidate site to ChannelWebsite folder"`
5. `git push origin main --force`

**結果：** ChannelWebsite 資料夾現在就是網站的工作目錄，所有編輯直接在此進行即可。
