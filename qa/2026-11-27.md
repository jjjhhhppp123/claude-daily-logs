## 26. 自訂節點怎麼嵌入 ComfyUI
**Q：** 你是怎麼嵌入 comfyui 的?
**A：** ComfyUI 本身就有外掛機制：啟動時會掃 custom_nodes/ 底下每個資料夾，載入 __init__.py，讀取 NODE_CLASS_MAPPINGS 就把節點加進選單。
1. 建資料夾 custom_nodes/mannequin_depth/，裡面只有一個 __init__.py
2. 寫一個 Python 類別 MannequinDepthClean，用固定欄位描述節點：
   - CATEGORY="人偶姿勢"（右鍵選單分類）
   - INPUT_TYPES：人偶圖、原始深度兩個 IMAGE 輸入＋背景門檻/人偶最低灰階/身體模糊/頭部模糊/頭部羽化/頭部形狀 參數（介面上的滑桿與下拉選單）
   - RETURN_TYPES/RETURN_NAMES：深度圖、頭部範圍檢查 兩個輸出
   - FUNCTION="run"：按執行時呼叫的函式
3. 最後兩行註冊：NODE_CLASS_MAPPINGS={"MannequinDepthClean":...}、NODE_DISPLAY_NAME_MAPPINGS={...:"人偶 → 乾淨深度圖"}
4. 重開 ComfyUI → 雙擊空白處搜尋「人偶」就能拉出來
不用改 ComfyUI 本體、不用 Manager 安裝；要移除就把資料夾移走再重開。

## 27. 節點是否在 py 裡呼叫 SAM
**Q：** 所以你是在py呼叫sam嗎?
**A：** 對，在節點的 __init__.py 裡直接呼叫 SAM 的 Python 套件（segment_anything），沒有另外接 SAM 節點。
流程（sam_head 函式）：
1. import segment_anything（ComfyUI 環境裡已裝；沒有就自動改用橢圓）
2. 第一次執行時載入 models/sams/sam_vit_b_01ec64.pth，放進記憶體快取，之後不再重載；有顯卡用 GPU
3. 先用規則（頭頂往下找脖子）框出頭的大概範圍，取框的中心點
4. 把人偶圖＋這個中心點（一個「這裡是目標」的點提示）交給 SAM，SAM 回 3 個候選遮罩
5. 按信心分數挑，檢查合理性：不能比規則框大 1.5 倍以上（避免切到整個身體）、面積不能太小
6. 合格就用 SAM 頭形（稍微外擴留頭髮空間），都不合格就退回橢圓；用完清顯存
檢查圖：紫色＝SAM 切的頭，紅圈＝退回橢圓。

## 28. 人偶深度節點程式碼＋註解、連接方式
**Q：** 我可以看這個節點的程式碼嗎?，然後給我註解說明，我想知道節點的連接方式
**A：** 另存註解版 workflows/人偶深度節點_註解版.py（原 custom_nodes/mannequin_depth/__init__.py 不動）。
接線：載入圖片(人偶圖) 分兩條 → ①深度估計 Depth Anything → 本節點「原始深度」；②直接 → 本節點「人偶圖」。
輸出：「深度圖」→ 套用 ControlNet 的 image＋預覽；「頭部範圍檢查」→ 預覽（紫＝SAM、紅圈＝橢圓）。
程式結構：_np/_img 格式轉換 → find_head 規則找脖子 → sam_head 用頭中心點提示 SAM → clean 主流程（遮罩、深度重映射 90~255、身體/頭部兩種模糊、頭部遮罩合成、檢查圖）→ class 定義介面（INPUT_TYPES 左邊輸入與欄位、RETURN_TYPES 右邊輸出、FUNCTION=run）→ NODE_CLASS_MAPPINGS 註冊。
接點型別相同才能互接（這裡都是 IMAGE）；ID MannequinDepthClean 不可改，否則舊 workflow 找不到節點。

## 29. 自訂節點怎麼宣告參數欄位
**Q：** 我要怎麼宣告讓節點顯示出我的參數設定?
**A：** 在類別的 INPUT_TYPES 回傳字典裡宣告，每一項＝欄位名: (型別, 選項)。
- 型別：IMAGE/MASK/LATENT 等→接線點；INT/FLOAT→數字欄（min/max/step/default，display:"slider" 變滑桿）；STRING→文字（multiline:True 多行、placeholder）；BOOLEAN→開關（label_on/label_off）；["A","B"] 清單→下拉選單
- 共通選項：default、tooltip、forceInput:True（只留接線點不顯示欄位）
- 分區：required 必填、optional 可不接（run 要給預設值）、hidden 不顯示
- run(self, ...) 參數名要和欄位名一致；改完重開 ComfyUI，舊節點需重新拉一個才會更新欄位

## 30. INPUT_TYPES 是否固定命名
**Q：** INPUT_TYPES 是固定的命名嗎?
**A：** 是，ComfyUI 程式寫死去找這些名字，拼錯或大小寫不同就認不到。
- 固定（必須照寫）：INPUT_TYPES（要加 @classmethod）、RETURN_TYPES、FUNCTION、CATEGORY、NODE_CLASS_MAPPINGS、NODE_DISPLAY_NAME_MAPPINGS；字典鍵 required/optional/hidden；選項鍵 default/min/max/step/tooltip 等；型別 IMAGE/INT/FLOAT…
- 選填但名稱固定：RETURN_NAMES、OUTPUT_NODE、DESCRIPTION、OUTPUT_TOOLTIPS、IS_CHANGED
- 可自己取：類別名、FUNCTION 指向的方法名（如 run）、欄位名（可中文）、輔助函式名、資料夾名
